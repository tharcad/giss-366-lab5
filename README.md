# GISS 366 Lab 05
For What I built it was a set of maps encompassing the regions of Tombstone, Bisbee, & Sierra Vista Arizona. They focus on map controls and complexity that can be added to either better distinguish objects on the map to style choice and addition of controls for better viewing.
